# دفتر الحساب — النسخة المصححة للنشر التلقائي

هذه الحزمة لا تضيف GitHub Actions ولا تحتاج إلى Secrets جديدة، لأن مشروع Cloudflare الحالي لديه إعداد بناء ظاهر في لوحة التحكم مرتبط بالمستودع Geoman1262/Business والفرع main، وأمر النشر npx wrangler deploy. اترك إعدادات البناء الحالية كما هي.

## التحديث الصحيح
1. فك ضغط الحزمة.
2. ارفع/استبدل الملفات الموجودة في جذر مستودع GitHub `Geoman1262/Business` على الفرع `main` (لا ترفع ملف ZIP نفسه بدل الملفات).
3. اعمل Commit على `main`.
4. افتح Cloudflare → Workers & Pages → business → Build history وتحقق من ظهور بناء جديد بعد الـ Commit.
5. إذا لم يظهر بناء جديد، افحص إعدادات Builds/Deployments في Cloudflare؛ لا تضف مسار نشر ثانيًا ولا Secrets عشوائية.

## البيانات والتحديث
- مفتاح التخزين في التطبيق هو `debt_book_v1`. لا تغيّره ولا تمسح بيانات المتصفح.
- البيانات المحلية تبقى على المتصفح/الجهاز نفسه؛ لا تنتقل تلقائيًا إلى جهاز آخر. صدّر نسخة احتياطية قبل تحديث كبير.
- `sw.js` يفحص النسخة الجديدة عند فتح التطبيق والعودة إليه، وكذلك دوريًا أثناء بقائه مفتوحًا.
- لا يضمن تحديث الواجهة وحده استعادة بيانات سبق أن فُقدت أو حُذفت.
