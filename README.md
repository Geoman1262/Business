# دفتر الحساب — النشر والتحديث التلقائي

هذه الحزمة مبنية على نسخة دفتر الحساب ذات مفتاح التخزين المحلي `debt_book_v1`، وتحتفظ بمنطق الديون والدفعات والترقيم وFIFO. لا يقوم التحديث بمسح `localStorage`.

## تفعيل النشر التلقائي من GitHub إلى Cloudflare

أُضيف GitHub Actions workflow ينشر عند كل push إلى الفرع `main`. لكي يعمل، أضف هذين السرّين في مستودع GitHub:

1. افتح المستودع → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**.
2. أضف `CLOUDFLARE_API_TOKEN` بقيمة API Token من Cloudflare لديه صلاحية نشر Workers.
3. أضف `CLOUDFLARE_ACCOUNT_ID` بقيمة Account ID من Cloudflare.
4. ارفع محتويات هذه الحزمة إلى جذر المستودع، مع مجلد `.github/workflows`، ثم اعمل Commit على `main`.
5. افتح تبويب **Actions** في GitHub لمتابعة النشر. يمكن تشغيله يدويًا من **Run workflow**.

إذا كان Cloudflare Git integration ينشر المشروع تلقائيًا أصلًا، فلا تفعّل مسار نشر ثانٍ قبل التحقق من إعدادات المشروع لتجنب عمليتي نشر متزامنتين.

## تحديث التطبيق المثبّت

ملف `sw.js` الجديد يفحص التحديث عند فتح التطبيق، وعند عودة التطبيق إلى الواجهة، وكل دقيقة أثناء عمله. عند تفعيل Service Worker جديد يعيد تحميل الواجهة تلقائيًا. ملفات الحساب محفوظة في `localStorage`، ولا تمسحها عملية تحديث الكاش.

## مهم لحماية البيانات

- لا تغيّر `KEY='debt_book_v1'` في `index.html`.
- لا تضغط زر «حذف كل البيانات».
- البيانات الحالية محلية على نفس المتصفح/الجهاز؛ هذه الحزمة لا تنقلها تلقائيًا إلى جهاز آخر ولا تنشئ قاعدة بيانات سحابية.
- قبل أي تحديث كبير، صدّر نسخة احتياطية من داخل التطبيق.
