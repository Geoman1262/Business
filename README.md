# دفتر الحساب

هذه نسخة كاملة للنشر على نفس مشروع Cloudflare Workers Static Assets. ضع الملفات الخمسة في جذر المستودع: `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `wrangler.toml`.

## الميزات
- الواجهة الأصلية المصممة للموبايل: الرئيسية، السجل، الإعدادات.
- عرض آخر العمليات وسجل العمليات؛ اضغط على أي عملية لإظهار التفاصيل.
- تفاصيل الدين: القيمة الأصلية، المدفوع، المتبقي، تاريخ الدين، حالة السداد، وتواريخ الدفعات.
- تفاصيل الدفعة: تاريخها ومقدارها وكيف وُزّعت على أقدم الديون أولاً (FIFO).
- بحث وفلترة حسب التاريخ والنوع، اسم الشخص، تصدير واستعادة نسخة JSON.
- حفظ محلي على الجهاز ودعم PWA.

## تنبيه مهم عن البيانات
التطبيق يستخدم مفتاح التخزين `debt_book_v1` نفسه للمحافظة على بيانات هذه النسخة الموجودة في المتصفح. لا تمسح بيانات الموقع/المتصفح. خذ نسخة احتياطية من الإعدادات قبل استبدال الملفات. البيانات المحلية لا تنتقل تلقائياً بين الأجهزة أو المتصفحات.

في Cloudflare Workers Builds، استخدم أمر النشر المعتاد للمشروع نفسه. لا تنشئ Worker جديداً.
