دفتر الحساب — حزمة إضافة محاسبة (Patch)

المحتويات:
- accounting.html: واجهة محاسبة مستقلة للإدارة.
- worker-accounting-patch.js: كتل إضافية يجب دمجها يدوياً داخل worker.js.
- README.txt: التعليمات وحدود الاختبار.

حماية النظام الحالي:
- لا تستبدل worker.js بهذا الملف.
- لا تعدّل index.html أو portal.html.
- لا تغيّر سجل الدين أو طريقة التسديد الحالية.
- قاعدة المحاسبة الجديدة order_accounting منفصلة عن سجل العميل.
- يتم ربط العملية بالطلب المعتمد عبر order_id وSerial Number فريد.

الفحص:
تم فحص بنية HTML/JS بشكل ثابت فقط عند إنشاء الحزمة. لم يتم إجراء اختبار تكامل على Cloudflare Worker أو D1 الحقيقي، ولذلك هذه ليست نسخة جاهزة للنشر مباشرة.
قبل الدمج، يجب مراجعة worker.js الحالي ودمج الكتل في الأماكن الموضحة ثم اختبار الطلب والموافقة والتسديد والإشعارات على نسخة staging.

ملاحظة مهمة حول الدفعات:
النظام الحالي يسجّل الدفعات على مستوى العميل وليس على عملية منفردة. لذلك الحزمة تعرض الدين المتبقي الإجمالي للعميل، ولا توزّع الدفعات على كل عملية. إذا أردت المتبقي لكل Serial Number، يجب تحديد قاعدة توزيع (مثلاً الأقدم أولاً) قبل تفعيل هذا التفصيل.
