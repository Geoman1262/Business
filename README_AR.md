# مركز الإشعارات داخل التطبيق

الحزمة تحتوي على نسختين معدلتين فعلياً:
- `worker.js`
- `portal.html`

أضيف صندوق «مركز الإشعارات» داخل بوابة العميل، وعدّاد للإشعارات غير المقروءة، وتحديد إشعار كمقروء أو قراءة الكل. تحفظ الإشعارات في D1، وتبقى محاولة إشعارات الهاتف موجودة.

## قبل الرفع
هذه الملفات بُنيت على ملفات مشروع Business المتوفرة في حزمة التكامل السابقة، وليست تأكيداً بأنها مطابقة تماماً لآخر نسخة موجودة الآن على GitHub. لتجنّب استبدال أي تعديلات أحدث في مشروعك، قارن الملفين مع نسختك الحالية قبل رفعهما. لم يتم نشر أي شيء إلى Cloudflare.

## الملفات الأخرى
لم أغيّر `index.html` أو `sw.js` أو `wrangler.toml` ضمن هذه الإضافة.
