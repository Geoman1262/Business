# جرس الإشعارات — نسخة معدّلة

يحتوي هذا الأرشيف على `portal.html` المعدّل كاملاً و`worker.js` المتوافق مع واجهة الإشعارات الموجودة في هذه الحزمة.

## التعديل
- إزالة صندوق الإشعارات الكبير من أعلى الصفحة.
- إضافة جرس 🔔 صغير بجانب اسم العميل مع عدد غير المقروء.
- عند الضغط على الجرس تظهر قائمة الإشعارات؛ والضغط خارجها يغلقها.
- الإبقاء على فتح الإشعارات وقراءة إشعار واحد وخيار «قراءة الكل» والتحديث.
- لا تغيير على كود إشعارات الهاتف داخل `sw.js`.

## قبل الرفع
1. خذ نسخة احتياطية من `portal.html` و`worker.js` في مشروعك.
2. استبدل الملفين بهذين الملفين فقط إذا كانت نسخة `worker.js` المرفقة هي نفس نسخة نظامك التي تدعم الإشعارات داخل التطبيق.
3. انشر الملفات ثم حدّث صفحة العميل تحديثاً كاملاً.

تم التحقق آلياً من وجود عناصر الجرس والنافذة، ومن سلامة صياغة JavaScript في الصفحة، ومن وجود مسارات API المطلوبة في worker.js المرفق. لم يتم نشر التعديل إلى Cloudflare.
