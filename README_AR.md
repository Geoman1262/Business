# إضافة مركز الإشعارات داخل التطبيق

تحتوي الحزمة على `apply_patch.py`. شغّله من جذر مستودع `Geoman1262/Business` بعد تنزيل/نسخ ملفات المستودع، حيث يوجد `worker.js` و`portal.html`.

سيُنشئ السكربت مجلد `inapp-notifications-output` وفيه نسختان معدلتان، ولن يكتب فوق الملفات الأصلية. ارفع النسختين الناتجتين إلى GitHub بعد مراجعتها. باقي ملفات المشروع لا تتغير.

الإضافة تحفظ نسخة من إشعارات الأحداث الحالية في D1 وتعرضها داخل بوابة العميل مع عدّاد غير المقروء وخيار قراءة الكل. إشعارات الهاتف الحالية تبقى مفعلة كما هي. جدول الإشعارات ينشأ تلقائياً.

السكربت يتحقق من نقاط الإدراج ويوقف نفسه إذا لم تطابق النسخة الحالية من الملفات، لتجنب تغيير غير مقصود.
