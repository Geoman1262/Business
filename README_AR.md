# حزمة إضافة إشعارات Push — دفتر الحساب

## مهم قبل الاستخدام
هذه حزمة ملفات مساعدة للإضافة وليست نسخة كاملة جاهزة للاستبدال مكان ملفات المشروع.
لم يتم تعديل أي ملف قديم في GitHub أو نشر أي شيء. لا تستبدل `worker.js` أو `portal.html` أو `sw.js` بهذه الملفات.
السبب: الإشعارات تحتاج دمجاً دقيقاً مع مسارات تسجيل الدين والدفعات الموجودة فعلياً، وتخزين اشتراك كل عميل بأمان، وإعداد مفاتيح Push على Cloudflare. رفع ملفات مساعدة وحدها لا يفعّل الإشعارات.

## المطلوب حتى تصل الإشعارات والعميل غير متصل
1. تفعيل HTTPS (متوفر عادةً على Cloudflare Pages/Workers).
2. استخدام Web Push مع مفاتيح VAPID محفوظة كـ Cloudflare secrets.
3. إضافة اشتراك Push لكل عميل مربوطاً بمعرّف حسابه.
4. استدعاء الإرسال بعد نجاح تسجيل الدين وبعد نجاح تسجيل دفعة فقط.
5. إضافة أحداث `push` و`notificationclick` إلى Service Worker الحالي مع الحفاظ على كوده القديم.
6. اختبار Android/Chrome؛ وصول الإشعار يتطلب موافقة العميل واتصال الجهاز بالإنترنت، وقد يصل بعد إعادة تشغيل الجهاز.

## خطة الدمج الآمنة
- لا تغيّر طريقة حساب الرصيد أو شكل entries أو التقارير.
- لا ترسل إشعاراً قبل حفظ الحركة بنجاح.
- لا تُظهر مفاتيح الإدارة أو مفاتيح VAPID الخاصة للعميل.
- إذا فشل إرسال الإشعار، يجب ألا يفشل تسجيل الدين أو الدفعة.
- لا ترفع هذه الحزمة قبل دمجها واختبارها على نسخة تجريبية.
