تعديل الجرس 🔔 في واجهة العميل

هذا الأرشيف يحتوي على سكربت تعديل آلي، وليس ملف portal.html جاهزاً للاستبدال. السبب أن ملف portal.html يجب أن يكون مطابقاً تماماً لنسختك الحالية حتى لا تضيع وظائف أخرى.

الخطوات:
1. نزّل portal.html الحالي من مستودع GitHub إلى مجلد على الكمبيوتر.
2. ضع apply_bell_patch.py في نفس المجلد.
3. شغّل: python apply_bell_patch.py
4. سيحفظ السكربت نسخة احتياطية portal.html.backup ويعدّل portal.html.
5. راجع الملف ثم ارفعه إلى GitHub مكان portal.html، وانتظر النشر.
6. حدّث صفحة العميل تحديثاً كاملاً.

التغيير: جرس صغير بجانب اسم العميل، شارة بعدد غير المقروء، قائمة منسدلة عند الضغط، وقراءة الكل. لا يغيّر worker.js أو sw.js.
