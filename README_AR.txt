تعديل واجهة الإشعارات إلى جرس صغير

هذا ZIP يحتوي على تعليمات التعديل وليس ملف portal.html كاملاً، لأنني لا أريد أن أضع ملفاً ناقصاً مكان ملفك الحالي أو أخاطر بوظائف موجودة.

المطلوب تعديل portal.html فقط:
1. خذ نسخة احتياطية.
2. اتبع الخطوات في notification-bell-patch.txt.
3. لا تغيّر worker.js أو sw.js؛ إشعارات الهاتف تبقى كما هي.
4. بعد الحفظ، انشر تحديث ملفات الموقع ثم حدّث صفحة العميل.
