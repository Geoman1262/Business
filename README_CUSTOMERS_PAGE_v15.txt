دفتر الحساب — صفحة إدارة العملاء

التعديل في هذه النسخة:
- إضافة تبويب «العملاء» إلى شريط التنقل الرئيسي.
- عرض عدد ملفات العملاء وإجمالي الأرصدة المتبقية المستحقة من العملاء.
- قائمة منسدلة بكل العملاء مع رصيد كل عميل.
- عرض إجمالي الديون المسجلة والدفعات ورصيد العميل المحدد قبل الفتح.
- زر «موافق — فتح حساب العميل» ينقل إلى ملف العميل المختار داخل التطبيق الرئيسي، مع بقاء إمكانيات الإضافة والتعديل الحالية.
- قائمة مختصرة بكل العملاء وأرصدتهم، والضغط على عميل يفتح حسابه.
- توجيه اختصار «البحث عن عميل» إلى صفحة العملاء.
- رفع إصدار ذاكرة التخزين المؤقت للخدمة إلى v5 حتى يحصل التطبيق على الملفات المحدثة.

مصدر البيانات هو ملفات العملاء المحلية الحالية debt_book_clients_v1؛ لم تتغير مفاتيح التخزين أو بنية بيانات الحسابات.

الفحوص: فحص صياغة JavaScript المضمّن عبر Node.js وفتح ملف ZIP بعد إنشائه. لم يتم النشر على Cloudflare أو اختبار واجهة الموقع المباشر.
