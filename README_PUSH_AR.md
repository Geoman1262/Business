# إشعارات Push — دفتر الحساب

## ما الذي أضيف؟
- زر «تفعيل الإشعارات» في صفحة العميل.
- تسجيل اشتراك كل جهاز وربطه بحساب العميل عبر token الموجود في رابط الحساب.
- إرسال إشعار بعد اعتماد تسجيل دين، وبعد نجاح تسجيل دفعة من لوحة الإدارة.
- اختبار تلقائي عند تفعيل الإشعارات.
- دعم استقبال الإشعار عند إغلاق صفحة الحساب عبر Service Worker.

## إعداد Cloudflare قبل التشغيل (ضروري)
1. على جهاز فيه Node.js، شغّل `node generate-vapid-keys.mjs` داخل مجلد المشروع.
2. خذ القيم المطبوعة، ثم أضفها كـ Worker Secrets/Variables في Cloudflare: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`. المفتاح الخاص لا تضعه في ملفات HTML ولا تنشره.
3. نفّذ migration `migrations/0003_push_subscriptions.sql` على D1 المرتبط بالتطبيق، أو اترك `worker.js` ينشئ الجدول تلقائياً عند أول اشتراك.
4. انشر المشروع على HTTPS. بعد النشر افتح رابط حساب العميل على Chrome/Android، واضغط «تفعيل الإشعارات» واسمح بها.
5. يجب أن يظهر إشعار اختبار. بعدها جرّب اعتماد دين أو تسجيل دفعة.

## ملاحظات
- لا يحتاج العميل أن تبقى صفحة الحساب مفتوحة بعد نجاح الاشتراك.
- يجب أن يكون الجهاز متصلاً بالإنترنت وقادراً على استقبال إشعارات المتصفح. إعدادات توفير البطارية قد تؤخرها.
- الإشعار لا يغيّر حساب العميل أو الرصيد؛ هو يُرسل بعد نجاح حفظ الحركة. فشل الإشعار لا يلغي الدين أو الدفعة.
- مفاتيح VAPID غير موجودة داخل ZIP لأسباب أمنية؛ يجب إعدادها على Cloudflare.
- تم الحفاظ على الملفات الأصلية وإضافة ميزات Push فقط، لكن يجب اختبارها على نسخة تجريبية قبل اعتمادها نهائياً.
