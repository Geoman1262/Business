تصحيح رابط مراجعة الطلب — v28

التعديل المحدد:
- الرابط الذي يُرسل لصاحب التطبيق أصبح /review?token=... وليس /api/health.
- Worker يوجّه /review و/order-review.html صراحةً إلى ملف HTML order-review.html مع الحفاظ على token.
- أُضيف /review إلى assets.run_worker_first.
- لم تُغيّر قاعدة البيانات أو ADMIN_KEY ولم تُحذف بيانات.

طريقة النشر: انشر ملفات الحزمة من جذر المشروع مع الحفاظ على ربط D1 والـ Secret الحاليين. لا تشغّل migrations من جديد إذا كانت مطبّقة. بعد النشر أنشئ طلبًا جديدًا؛ لا تختبر رابطًا قديمًا من رسالة سابقة.

التحقق المحلي: فحص صياغة JavaScript وسلامة ZIP. لم يتم النشر إلى حساب Cloudflare الحقيقي أو اختبار قاعدة البيانات الحية من هذه البيئة.
