تصحيح فعلي لمسار طلبات العملاء — دفتر الحساب

ما الذي تغير؟
- أضيفت معالجة أخطاء حول مسارات /api/* حتى يرجع الخادم JSON عند حصول خطأ، بدل صفحة HTML التي تسبب Unexpected token '<' في بوابة العميل.
- أُرفق migration إنشاء جدول client_orders المطلوب لطلبات الشراء/الدين.
- تم فحص صياغة worker.js بواسطة node --check بنجاح.

قبل النشر:
1) خذ نسخة احتياطية من مشروع GitHub الحالي.
2) استبدل worker.js بهذا الملف.
3) تأكد أن migrations/0002_client_orders.sql موجود في المشروع.
4) من Terminal داخل المشروع نفّذ:
   npx wrangler d1 migrations apply business-clients --remote
5) راجع مخرجات الأمر وتأكد أنه نجح، ثم انشر:
   npx wrangler deploy

مهم:
- لا تغيّر اسم قاعدة البيانات أو ربط DB أو Secret ADMIN_KEY.
- لا تنفّذ migration إذا كانت قد طُبقت سابقاً إلا بعد مراجعة حالة migrations؛ ملف SQL يستخدم IF NOT EXISTS، لكن راجع سجل migrations قبل أي إجراء.
- هذا الملف لم يُنشر على Production ولم يُختبر ضد قاعدة البيانات الحية.
